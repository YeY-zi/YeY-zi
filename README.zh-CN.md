## 代表项目

### [Research Evidence Workbench 科研证据工作台](https://github.com/YeY-zi/research-evidence-workbench)

个人产品原型，将研究问题、公开来源与人工核对的证据卡片连接起来。仓库包含问题定义、PRD、可点击原型、本地演示和有记录的离线检查。

**当前范围：**演示使用小型人工整理资料集进行规则匹配，也支持手动登记来源。自动文献检索、AI 生成和真实用户验证仍待完成。

### [Olist 客户复购分析](https://github.com/YeY-zi/Predict_repurchase)

基于 [CercaTrovato 原项目](https://github.com/CercaTrovato/olist-repurchase-analysis)开展并保留归属说明的扩展分析。通过历史客户快照研究未来 90 天复购，新增清洗审计，并比较群体标记、历史品类特征与初版分类器。

**实验发现：**群体标记提高了验证期 AP，但没有改善较晚的探索性测试结果。仓库保留两种结果、基础材料来源、复现脚本和汇报材料。历史购买预测不能证明营销活动带来的增量。

### [Research Agent Lab 科研工具调用实验](https://github.com/YeY-zi/research-agent-lab)

在 AI 编程助手协助下完成的学习原型，将论文检索、证据记录、受控 Python 实验、评价与报告连接为工具流程。比较固定工作流和本地 Qwen 通过 MCP 调用工具的表现，保留成功调用、错误和实验轨迹。

**当前范围：**预定义任务下的受约束工具调度。它不自动实现检索到的论文，也没有证明自主科研能力。

### [ECG 时间序列预测](https://github.com/YeY-zi/ecg-tsfm-exploration)

在 AI 助手协助下开展的波形预测学习项目，在有记录的 MIT-BIH 划分上比较简单基线、CNN 和 PatchTST-style 模型。仓库保留预处理选择、实际训练日志、逐记录误差和困难波形案例。

**当前范围：**单种子的短窗口预测实验。它不属于 PatchTST 官方完整复现、基础模型预训练或临床诊断评价。

## 我的项目方法

- 先定义问题，以及分析结果可能支持的决策。
- 保留数据来源、假设、实验设置和结果之间的对应关系。
- 与简单基线比较，并记录没有成功的尝试。
- 说明哪些内容已经实现、哪些来自改编，以及哪些仍需验证。

我使用 AI 编程辅助，并在相关仓库说明其参与范围；也在通过代码检查和复跑逐步建立独立理解。
