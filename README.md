## Selected work

### [Research Evidence Workbench](https://github.com/YeY-zi/research-evidence-workbench)

A personal product prototype for connecting research questions, public sources, and manually checked evidence cards. The repository includes a problem brief, PRD, clickable prototype, local demonstration, and documented offline checks.

**Current scope:** the demonstration uses rule matching over a small curated collection and supports manual source registration. Automated literature retrieval, AI generation, and real user validation remain future work.

### [Olist Repurchase Analysis](https://github.com/YeY-zi/Predict_repurchase)

An attributed extension of [CercaTrovato's Olist project](https://github.com/CercaTrovato/olist-repurchase-analysis), using historical customer snapshots to study 90-day repurchase. The extension adds a cleaning audit and a comparison of segment and category features against the original classifier.

**Finding:** segment labels improved validation AP but did not improve the later exploratory test. The repository preserves both outcomes, the original source attribution, reproducible scripts, and presentation materials. Historical purchase prediction does not establish marketing uplift.

### [Research Agent Lab](https://github.com/YeY-zi/research-agent-lab)

An AI-assisted learning prototype that connects paper search, evidence records, a controlled Python experiment, evaluation, and reporting through tools. It compares a fixed workflow with local Qwen tool calling over MCP and retains successful calls, failures, and experiment traces.

**Current scope:** constrained tool scheduling over predefined tasks. It does not independently implement retrieved papers or establish autonomous research capability.

### [ECG Time-Series Forecasting](https://github.com/YeY-zi/ecg-tsfm-exploration)

An AI-assisted forecasting study comparing simple baselines, a CNN, and a PatchTST-style model on a documented MIT-BIH record split. The repository preserves preprocessing choices, actual training logs, per-record errors, and difficult waveform examples.

**Current scope:** a single-seed short-window forecasting experiment. It is not an official full PatchTST reproduction, foundation-model pretraining, or a clinical diagnosis evaluation.

## How I approach projects

- Define the question and the decision it could support.
- Keep source data, assumptions, experiment settings, and results traceable.
- Compare with a simple baseline and preserve unsuccessful attempts.
- Explain what was implemented, what was adapted, and what still needs validation.

I use AI coding assistance and document that contribution in the relevant repositories. I am continuing to build independent understanding through code review and reproduction.
